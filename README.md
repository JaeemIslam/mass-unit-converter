# Mass Unit Converter

A Python-based unit converter that converts different mass measuring units into each other.

## Supported Units
- Ton
- Kilogram
- Gram
- Milligram
- Pound
- Ounce
- Crate

More units will be added in future updates.

## Project Structure
```text
mass-unit-converter/
├── MassUnitConverter.py
├── calculation.py
└── matchCases.py
```
## Running the Project
- Download the repo
- Run MassUnitConverter.py

Just a fun beginner project in python.
